# Circular Smart MoBel Plastic Tree

## Technologies
- Frontend: HTML, CSS
- Backend: Node.js, Express.js
- Containerization: Docker
- Orchestration: Docker Compose

## API Endpoints

### Authentication

POST /register
POST /login
POST /logout
POST /change-password

## Run Project

```bash
docker compose up --build
```

Backend URL:

http://localhost:3000
